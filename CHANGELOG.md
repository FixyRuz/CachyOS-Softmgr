# Catatan Perubahan

## 4.1.0 — 17 November 2026

- Merapikan UI CachyOS Softmgr dengan tema gelap/terang, ikon konsisten, dan dialog yang lebih mudah dibaca.
- Menambahkan tab penggunaan penyimpanan untuk root, home, aplikasi, data Flatpak, dan cache Pacman.
- Menampilkan daftar pembaruan Pacman yang terdeteksi saat pembaruan Pacman/AUR dipilih.
- Menambahkan peringatan paket sistem penting saat penghapusan dan mempertahankan konfigurasi paket sebagai `.pacsave` bila Pacman memerlukannya.
- Menampilkan nomor versi proyek pada judul jendela.

## 4.0.0

- Membangun ulang backend transaksi, worker, integrasi Pacman/AUR/Flatpak, pencarian, tema, dan pemantauan transaksi.
