# Kebijakan Keamanan

Gunakan versi terbaru yang tercantum pada halaman rilis proyek.

Jangan sertakan kata sandi, token, tangkapan dialog autentikasi, atau log yang memuat informasi pribadi saat melaporkan masalah. Setelah repositori GitHub dibuat, aktifkan **Private vulnerability reporting** dan gunakan kanal itu untuk kerentanan keamanan. Gunakan issue publik untuk laporan bug umum yang tidak memuat data sensitif.

Paket AUR menjalankan PKGBUILD dari sumber AUR sebagai pengguna saat ini. Tinjau sumber paket yang dipasang dan jangan menyetujui build yang tidak Anda percaya.
